# Parrot Docs

Parrot Docs covers user guides and documentation feedback for Parrot.

## Scope

- Getting started, setup and everyday use.
- Troubleshooting and compatibility guidance.
- Corrections, missing information and documentation translations.

## Current status

This repository provides public issue tracking and documentation planning. Read the published guides on the [Parrot documentation site](https://parrotvoice.app/docs/). Product source code is not currently published here.
